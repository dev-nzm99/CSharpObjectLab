## 📌 About

This repository is a **chapter-by-chapter guide to Object-Oriented Programming in modern C#**.
This page is a navigation hub only. Every lesson, diagram, interview question and exercise lives inside its own chapter folder.

**Each chapter includes:** concepts · syntax · examples · diagrams · common mistakes · best practices · interview questions · practice problems.

## 📖 Recommended Study Order

1. Follow the chapters **in numeric order**. Each one builds on the previous.
2. Read the chapter, then run its project in [`examples/`](./examples).
3. Attempt the chapter's problems in [`exercises/`](./exercises) **before** checking [`solutions/`](./solutions).
4. Revisit the **Interview Questions** section of each chapter before interviews.
